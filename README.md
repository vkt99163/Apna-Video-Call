# 📹 Apna Video Call

A full-stack, real-time video conferencing web application designed for seamless peer-to-peer audio/video
communication, instant messaging, and meeting management.

---

## ✨ Key Features

- 🎥 **Real-time Video & Audio:** Peer-to-peer high-quality video and audio calling using WebRTC.
- 💬 **In-Call Chat:** Instant messaging with participants during active sessions via Socket.io.
- 📺 **Screen Sharing:** Effortlessly share your desktop or specific application windows with participants.
- 🔒 **Room-based Meetings:** Join or create custom meeting rooms with secure room IDs.
- 📜 **Meeting History:** Track past sessions and user meeting records stored securely.
- 🎨 **Modern UI:** Responsive, sleek glassmorphism design powered by Material-UI.

---

## 🛠️ Tech Stack

### **Frontend**
- **React.js** – UI library
- **Material-UI (MUI)** – UI components & glassmorphism styling
- **WebRTC** – Peer-to-peer audio/video stream transmission
- **Socket.io-client** – Real-time signaling & communication

### **Backend**
- **Node.js** & **Express.js** – Server architecture and API endpoints
- **Socket.io** – Real-time event handling & room management
- **MongoDB Atlas** – NoSQL database for user data and meeting history
